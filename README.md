# HLA Fusion Report Splitter

A lightweight, GUI-based tool for splitting multi-report PDF files generated by HLA Fusion into individual sample reports. Built with Python and Tkinter, this utility identifies and extracts each report based on its type (PRA or SAB, Class I or Class II) and names the output files using the Sample ID.

> ⚠️ **Important**: This tool is intended for **research use only**. It is not validated for clinical or diagnostic purposes.

---

## 💡 Features

- ✅ Simple and clean graphical interface  
- ✅ Automatically detects report type (PRA/SAB, Class I/II)  
- ✅ Extracts and names reports using Sample ID  
- ✅ Saves each report as an individual PDF  
- ✅ Supports both PRA and SAB formatted reports  
- ✅ Designed specifically for HLA Fusion output

## Installation

Ensure you have the required dependencies installed before running the scripts.

```sh
# Clone the repository
git clone https://github.com/shannonbarrera/HLA-SplitStack.git

# Navigate into the project directory
cd HLA-SplitStack

# Install dependencies
pip install -r requirements.txt
```
## 🖥️ How to Use

1. **Save the Reports in One PDF**
   Make sure the "1 Sample Per Report" checkbox is checked.
   This ensures that the first page of each report contains the text "Page 1 of".
   
1. **Launch the Application**  
   If you're using the EXE version, just double-click `HLA-SplitStack`.

2. **Select the PDF File**  
   Click **"Select file"** and choose the PDF report you'd like to split.

3. **Split Reports**  
   Click **"Split file"**. The program will extract each individual report and save it in the same folder as the original file.

## 📦 Building the EXE with PyInstaller

To create a standalone Windows executable:

1. Install PyInstaller:

```bash
pip install pyinstaller
```

2. Build the executable:

```bash
pyinstaller --onefile --windowed reportsplittergui.py
```

- `--onefile`: Bundles everything into a single EXE  
- `--windowed`: Hides the terminal window on launch (no command prompt)

or

```bash
pyinstaller reportsplittergui.spec
```

This will generate the `.exe` in the `dist/` directory.

## ⚠️ Notes

- File naming is based on the "Sample ID" found within each report.
- Some cleanup is applied to Sample ID to ensure valid filenames.
- Currently tested on Windows with HLA Fusion-generated PDFs.
- Reports are assumed to follow specific formats:
- PRA reports: The first line of the first page contains "LABScreen PRA Bead Report"
- SAB reports: The first line of the first page contains "LABScreen Single Antigen Bead"
- The first page of each individual report contains "Page 1 of"
- The first page of a Class II report contains "Class II" more than 2 times.
- If a report is not a Class II report, it is a Class I report.
- Currently tested on Windows with HLA Fusion-generated PDFs.
- Can handle mixed Class I and II reports in the same file.
